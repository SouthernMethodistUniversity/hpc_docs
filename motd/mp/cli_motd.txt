POLICIES:
---------

Users must comply with all applicable laws, regulations, and SMU policies when
using HPC resources. This includes, but is not limited to, SMU’s acceptable use
policy: https://www.smu.edu/policy/8-information-technology/8-1-acceptable-use

Any commands, job submissions, file operations, processes, network access, etc. 
that jeopardize the security or stability of the HPC systems or negatively
impacts the ability for other researchers to use the systems may be terminated
without warning.

AI Usage:
---------

Users are expected to maintain meaningful human oversight of all AI tools and
agents. Providing an AI tool or agent autonomous or unattended control of HPC
system commands, job submission, file operations, processes, network access, 
etc. is prohibited. Usage of AI tools and agents is only allowed if you 
explicitly review and approve the commands, code, or other actions suggested by
the AI tools or agents.

=====================
$WORK is End of Life!
=====================

As of August 15, 2025 $WORK is end or life. Any data remaining in $WORK should be
moved as soon as possible. $WORK directories are subject to be deprovisioned 
(permanently deleted).

========================
Automatic $SCRATCH Purge
========================

Files older than 60 days stored in $SCRATCH will be automatically and 
permanently deleted on a regular cadence.

=======================
Reporting System Issues
=======================

If you believe something is not working correctly, please let us know by
emailing help@smu.edu with [HPC] included in the subject line and a
description of the issue and any steps to reproduce (if known.)

Please do not run system diagnostic tools yourself. While we appreciate the
effort, diagnostic tools can increase strain on the system and often make it
more difficult for us to observe issues with our system health monitoring tools.
